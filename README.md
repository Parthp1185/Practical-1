# CampusConnect – Student Services & Activities Portal

CampusConnect is a responsive single-page web application designed
for students to explore campus services, upcoming events,
student clubs and support facilities.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

## Bootstrap Features

- Navbar
- Grid System
- Cards
- Buttons
- Forms
- Badges
- Responsive Utilities

## Responsive Design

The website is designed for:

- Desktop
- Tablet
- Mobile
